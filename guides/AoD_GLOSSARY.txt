運用ルール
この用語集は、用語の確定度・出典・文脈依存性を分離して管理する。
列: source_term / target_term / status / provenance / handling / notes
status: approved = ユーザー確定、review = 既訳・プロジェクト根拠あり要レビュー、draft = 暫定、hold = 未解決で統一対象に使用しない。
approved への昇格はユーザーの明示承認時のみ行う。AI判断、既訳の使用頻度、機械的な多数決だけで approved に変更しない。
優先順位は approved > review > draft。hold は順位付けせず、解決するまで統一基準から除外する。
provenance: user / work / project / inherited。
handling: fixed = 基本訳固定、contextual = 文脈ごとに訳し分け、review_required = 解決まで使用保留。
全体QAでは approved + fixed を最も強い統一基準とする。review / draft は候補抽出に使えても自動確定しない。
contextual は機械的一括置換禁止。hold / review_required は統一基準として使用しない。
既存 target_ja は明示指示なしに自動上書きしない。
Protected Token、角括弧タグ、technical_review の扱いは AoD_STYLE_GUIDE を正本とし、本用語集には重複記載しない。
用語の登録対象・除外基準は AoD_STYLE_GUIDE「新規用語の登録ルール」を正本とする。
アイテム名称は AoD_GLOSSARY_ITEMS を正本とし、本コア用語集へ同一アイテム名を重複登録しない。複合アイテム名に含まれる人物名・地名・組織名・設定語等の構成要素は本書で管理する。
