# The Age of Decadence 日本語化MOD

The Age of Decadence 日本語化MOD。本文・UI・画像内の文字を日本語化。CMD形式の導入ツール付き、Python不要。フォント差し替え対応。

## ダウンロード

[リリースページ](https://github.com/gaiden8823/AgeOfDecadence_JP/releases/tag/v2026.10.10)の添付ファイル `AgeOfDecadence_JP_20261015_ja_spacing.zip` をダウンロードしてください。

GitHubが自動生成する「Source code」のZIPは導入用ではありません。ゲーム本体とフォントは同梱していません。

## 導入方法

1. ゲームを終了します。
2. ZIPを展開し、`日本語化.cmd` と `AoDJP` フォルダを `AoD.exe` と同じゲームフォルダに置きます。
3. `日本語化.cmd` をダブルクリックし、「番号：」に `2` を入力してEnterを押します。
4. 「導入しました」と表示されたら、`0` を押して画面を閉じます。
5. ゲームを起動し、オプションの言語一覧で「日本語」を選びます。

成功後にもう一度導入する必要はありません。既に導入済みの場合、確認・導入が競合として停止することがあります。

詳細はZIP内の `導入手順.txt`、または[導入手順](tools/release/導入手順.txt)をご覧ください。

## ツールのメニュー

| 番号 | 操作 |
| --- | --- |
| 1 | 導入前の確認（ゲームファイルは変更しません） |
| 2 | 日本語化を導入 |
| 3 | 元の状態へ戻す |
| 4 | 導入済みMODのフォントを変更 |

配布版の利用にPythonは不要です。導入ツールはWindowsのCMDとPowerShellを使用します。

## フォントの差し替え

ゲームを終了し、`AoDJP/fonts/` に日本語対応のttf・otf・ttcを置いて、ツールの `4` を選びます。複数候補があれば番号で選択してください。変更後はゲームを起動し直します。

フォルダが空の場合は、Windows側の **BIZ UDPMincho Medium** を使用します。標準フォントも存在しない場合は不足の案内が表示されます。標準に戻すには交換用フォントをフォルダ外へ移してから `4` を選んでください。使用中の交換用フォントは移動・削除しないでください。

文字サイズや画面配置は維持しますが、文字幅によって折り返し・はみ出しが変わることがあります。全フォントの互換性は保証しません。画像に焼き込まれた文字のフォントは変わりません。

## 元に戻す・更新する

ゲームを終了してツールの `3` を選びます。直近の有効なCMD版バックアップを使用します。導入後に対象ファイルを変更した場合は、安全のため復元を停止します。バックアップ・交換用フォント・セーブデータは削除しません。

更新時は、以前のツールで復元してから新しい配布物を配置・導入してください。導入済みMODへ無条件に重ねて上書きする方式ではありません。

## 画面がちらつく場合

画面のちらつきは、日本語化MODによるものではなく、元のゲームに由来する不具合です。

**AoD64.exeではなくAoD.exeから起動してください。**

## 確認範囲・注意事項

- 配布対象3,377ファイルの照合と、独立した試験環境での導入・復元を確認しています。
- 全画面・全ミッションの通しプレイは未完了です。文字サイズ125%では見切れが残る場合があります。
- 処理が止まった場合は画面の理由を確認してください。配布ファイルの破損・他の変更との競合・フォルダ階層の長さなどで停止する場合があります。
- PCの実行ポリシーを恒久変更したり、組織管理の制限を解除したりはしません。セキュリティソフトの警告がなくなる保証はありません。
