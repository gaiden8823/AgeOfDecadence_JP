# フォント基盤候補の検証

この候補はまだゲーム内表示を確認していません。既存 working は変更しません。

元環境の全 GUI フォント適用、言語再読み込み・文字サイズ変更・会話画面のフックと NPC 名のキャッシュ更新を独立モジュールにしました。職業名の固定訳、導入文の固定訳、1080 専用画像差し替え、会話フォルダ登録は含めません。翻訳は CSV と文字列ビルドが担当します。

## 準備

tools/font_basis.py prepare は source 全体を新しい font_validation フォルダへコピーし、候補モジュールだけを導入します。既存フォルダには上書きしません。約 2.1 GB のゲームコピー用容量が必要です。Windows に BIZ UDPMincho Medium が必要です。ゲームを終了して実行してください。

tools/font_basis.py build-text は最新の会話以外の CSV を下訳込みでビルドします。tools/font_basis.py install-text は YES 確認付きで font_validation に反映します。通常のツールの最新ビルド・復元状態とは分離しています。

ゲーム内確認は font_validation/AoD.exe を手動で起動してください。Steam 側の実行条件やセーブ保存場所はゲームの挙動に従います。既存セーブを上書きせず、検証用に別名で保存してください。

## 確認するもの

日本語言語の選択、オプション、キャラクター作成、インベントリ、ジャーナル、マップ、戦闘の技・説明・ログ、ロード表示、チュートリアル。文字サイズ 100% と 125%、設定変更後・再起動後も確認します。会話訳はこの検証ビルドに含めないので、会話の日本語確認は別途必要です。

文字列の中の font タグは全 GUI プロファイル変更だけでは直らないため、文字列ビルド側のタグ・DSO フォント処理も必要です。フォントモジュールのみで全画面が直ると扱わないでください。

## 戻す

ゲーム終了後、tools/font_basis.py restore-text で文字列反映を戻し、restore-font でモジュール導入を戻します。変更された対象は勝手に上書きせず停止します。ゲームが生成した DSO など未管理キャッシュは削除しません。モジュール定義がなくなれば、この候補モジュールは読み込まれません。

全 GUI の実機検証が通るまで、既存 working の JapaneseDisplayTest を削除・置換しないでください。ゲーム本体・フォント・抽出画像はこの候補の Git 管理対象に含めません。
