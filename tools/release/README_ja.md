# 日本語化MOD 配布候補

検証済みの追加MODと、必要な日本語の置き換えファイルを組み合わせた混合方式です。ゲーム本体・実行ファイル・元のアーカイブ・フォントファイルは含みません。現時点では個人用の配布候補で、公開版ではありません。

## 必要なもの

検証元と同じ版の正規ゲーム、Windowsに登録された BIZ UDPMincho Medium、Python 3.10以降。文字サイズ100%を基準に検証しています。ゲーム・翻訳原文・加工画像・フォントの公開配布に関する権利確認は別途必要です。

## 導入

ゲームを終了してください。他の日本語MODや変更済みファイルがある場合は、上書きせず停止します。まず予備チェックを実行し、その後に導入します。以下のゲームフォルダ部分をご自身の場所に置き換えてください。

```
python install_mod.py check "C:\ゲームフォルダ"
python install_mod.py install "C:\ゲームフォルダ"
```

起動後は言語一覧の「日本語（検証用）」を選びます。バージョンや元アーカイブが異なる場合は安全のため停止します。検証用ゲームへ重ねて導入するものではありません。

## 元に戻す

ゲームを終了し、導入時に表示されたバックアップ場所を指定します。導入後に対象ファイルを変更した場合は、安全のため復元を停止します。バックアップは復元後も保持します。

```
python install_mod.py restore "C:\ゲームフォルダ" --backup "C:\ゲームフォルダ\.aodjp_backups\導入日時"
```

新規導入したMODファイルは復元時に削除し、元からあったファイルはバックアップから戻します。空フォルダは残る場合があります。セーブは配布物に含めず、操作対象にもしていません。重要なセーブは別途保全してください。

## あとから訳を修正する

編集正本は作業環境の translations 内の dialogue_translation.csv（会話）、reviewed_translation_targets.csv（会話以外）、image_translation_targets.csv（画像文字）です。この配布物の内部文字列を直接編集するのではなく、正本から修正します。

1. 正本の該当訳だけを修正し、ID・原文・制御タグ・採用状態は保持します。
2. 現在の検証用ゲームへの差分反映を行います。本文、表示時変換表、ミッション、画像などの複数経路があるため、一般の古い全体ビルドをそのまま再適用してはいけません。後続のフォント・ボタン・表示経路修正を失う可能性があります。
3. テキストの対応位置と画像の配置を照合し、実ゲームで確認します。画像の訳文変更はCSVだけでは描画画像に反映されないため、既存の画像作成手順による再描画が必要です。
4. 検証済み構成から配布候補を再作成します。作業環境の release_tools/build_candidate.py が最新スナップショット作成手順です。
5. 利用者は旧版をバックアップで復元してから、新しい候補をチェック・導入します。無条件の重ね上書きはしません。

現時点の更新は担当者向け手順です。「CSVを編集して一操作で全経路へ反映する」統合更新機能はまだ完成していません。

## 確認範囲

会話29,906件、ミッション内訳文2,207箇所、動的変換247種類、表示フィールド241回、画像835ファイルを照合・検査しました。すべてのミッション・セーブ・画面の見た目を通しプレイした保証ではありません。配布候補の導入・復元は使い捨ての試験フォルダで検査します。
