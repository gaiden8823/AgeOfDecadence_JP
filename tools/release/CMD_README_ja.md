# CMD版の導入ツール

日本語化MOD 導入手順（2026-11-05 更新版）

■ ダウンロード・配置
GitHubのReleasesにある配布用ZIPをダウンロードします。
「Source code」のZIPは導入用ではありません。
ゲームを終了し、ZIPの中の「日本語化.cmd」と「AoDJP」フォルダを
AoD.exe と同じゲームフォルダに配置してください。

■ 初めて導入する場合
1. ゲームを終了します。
2. 日本語化.cmdをダブルクリックします。
3. PowerShellの日本語メニューで「2：日本語化を導入」を選択します。
4. 導入完了を確認したら、日本語メニューで「0」、続いてCMDの案内で「0」を選んで閉じます。
5. ゲームを起動し、オプションから「日本語」を選びます。

CMDの画面で「M」を選ぶと導入メニューへ戻り、「0」を選ぶとウィンドウを閉じます。
ゲームは自動起動しません。

■ その他の操作
1：導入前の確認（ゲームファイルの変更なし）
2：日本語化を導入
3：元の状態へ戻す
4：導入済みMODのフォントを変更

■ 既に導入済みの場合
日本語化を繰り返し実行しないでください。
更新する場合は、以前のツールで元の状態へ復元してから、
新しい配布版を配置・導入してください。
セーブデータは配布物に含まず、重要なセーブは別途バックアップしてください。

■ Windowsのセキュリティ・起動について
起動CMDのPowerShell指定は「-ExecutionPolicy Bypass」です。
この指定は起動したPowerShellプロセスだけに適用され、
PCの実行ポリシーを恒久変更しません。
ただし、そのプロセスでのスクリプト実行制限は緩和されます。
企業や組織のグループポリシーは優先される場合があります。
ダウンロード元を確認し、配布元を信頼できる場合に限り実行してください。
エラー時には画面に終了コードが表示されます。画面の内容をご確認ください。

■ フォント変更
ゲーム終了後、AoDJP/fonts に日本語対応のttf・otf・ttcを配置し、
メニューの「4」を選択します。配置されていない場合は
Windowsに導入済みのBIZ UDPMincho Mediumが使用されます。

■ 注意
日本語選択時にワールドマップの一部地点が表示・選択できない問題に対し、
地点を識別する内部値を修正しました。日本語の表示名は維持しています。
全画面・全ミッションの実機プレイ確認は未完了です。

■ 動作確認
ユーザーにより、CMDの起動・導入・復元と、日本語マップの地点表示・クリック・移動を確認済みです。
