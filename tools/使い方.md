# 日本語化ツールの使い方

更新日：2026-10-08。作業ルートは `C:\GameModding\AgeOfDecadence_JP` です。

## 編集するデータ

- 会話：`translations/dialogue_translation.csv`
- 会話以外：`translations/reviewed_translation_targets.csv`
- 画像文字：`translations/image_translation_targets.csv`（このツールでは反映しません）

CSVはUTF-8で保存します。用語集とスタイルガイドは `guides/` にあります。ID、原文、source_hash、タグ、変数を変更しないでください。外部翻訳サービスは使用しません。

訳文列はまだ `target_ja` と `target_draft` の2列です。状態名の統一と単一訳文列への移行は行っていません。新規・未承認の訳は `target_draft` に置きます。表示確認だけを理由に採用状態を上げないでください。

## ビルドする

`tools/日本語化ツール.cmd` を開き、番号を入力してEnterを押します。

| 番号 | 内容 |
|---|---|
| 1 | 会話以外をビルド。作業訳・レビュー訳も使用 |
| 4 | 会話も含めてビルド。作業訳・レビュー訳も使用 |
| 2 | 最新の成功ビルドをバックアップ付きで反映 |
| 3 | 直前の反映を戻す |
| 0 | 終了 |

ビルドではゲームを変更しません。`Build ready` が生成成功の表示です。STOPが出たら反映しないでください。成功しても全訳の校閲・全画面の表示確認が完了した意味ではありません。

### どの訳を使うか

`approved` 限定ではありません。保留対象を除き `target_ja` を優先し、空なら状態が `draft`・`review`・`approved`・`existing_mod` の行の `target_draft` を使います。訳がなければ原文を維持します。

`technical_review`・`hold`・`excluded`・`do_not_translate` は反映しません。ツールは翻訳CSVの訳文や採用状態を変更しません。生成先の manifest.json に使用した会話作業訳のID・件数と保留IDを記録します。古い内部表記 `trial` があっても別の承認限定モードを意味するものではありません。

`review` はユーザー承認済みを意味しません。旧MOD由来116件は、状態を `draft`、出所欄 `provenance` を `existing_mod` に整理済みです。チュートリアル38件も作業訳です。

## ゲームへ反映する

ゲームを終了し、ツールを再度開いて2を選びます。反映先が `C:\GameModding\AgeOfDecadence_JP\working` であることを確認してYESを入力します。反映前にバックアップを作ります。sourceやSteam本体を反映先にしないでください。

生成先は `builds/日時/`、バックアップは `backups/日時/`、状態管理は `tools/state/` です。アーカイブ本体とセーブデータは変更しません。英語・日本語の両方の読込先を用意するため、workingでは英語選択でも一部が日本語になります。

`working/AoD.exe` から起動し、日本語・文字サイズ100%で確認してください。125%では画面によって見切れが残ります。画像の加工・反映は対象外です。

## 戻す

ゲーム終了後に3を選びます。直前の反映で上書きしたファイルを復元し、その反映で新しく追加したファイルを削除します。バックアップは残ります。反映後に対象ファイルが別の処理で変更されていた場合は停止します。複数回反映した場合、3で戻るのは直前の1回だけです。

## Excel・環境設定

Excelで編集した場合もUTF-8 CSVとして保存するのが簡単です。XLSXを直接使う場合は別の入力フォルダを `--input` で指定し、同名CSVとXLSXを同時に置かないでください。基準CSVはtranslationsに残します。XLSXにはopenpyxlが必要です。CSVだけならPython標準ライブラリで動きます。

Pythonの場所は `AOD_TOOL_PYTHON`、ゲームの場所は `tools/state/settings.json` で指定します。相対パスは設定ファイルのフォルダ基準です。
