# 日本語化ツールの使い方

作業場所は `C:\GameModding\AgeOfDecadence_JP` に統一しました。

## 編集する翻訳データ

- 会話以外：`translations\reviewed_translation_targets.csv`
- 会話：`translations\dialogue_translation.csv`
- 画像内の文字：`translations\image_translation_targets.csv`（このツールの対象外）

CSV は UTF-8 で保存します。通常は target_ja（確定訳）を編集してください。ID・原文・source_hash・タグ・変数は変更しないでください。用語集とスタイルガイドは guides にあります。

この配置では translations が標準入力先です。旧 self_service/input は使用しません。旧ファイルを混ぜないでください。Excel から反映したい場合は、CSV として保存するのが簡単です。XLSX を直接使用する場合は別の入力フォルダを用意し、--input で指定します。元の reviewed_translation_targets.csv は基準データとして translations に残してください。指定した入力フォルダには同じ名前の CSV と XLSX を同時に置かないでください。

## ビルドと反映

1. ゲームを終了します。
2. `tools\日本語化ツール.cmd` を開きます。
3. 番号を入力して Enter を押します。

| 番号 | 内容 |
|---|---|
| 1 | 会話以外の target_ja のみビルド |
| 5 | 会話以外の下訳も含めてビルド |
| 4 | 会話も含めてビルド（会話以外は target_ja のみ） |
| 2 | 最新の成功ビルドをバックアップ付きで反映 |
| 3 | 直前の反映を戻す |
| 0 | 終了 |

5 は target_ja が空で status が draft の行に限って target_draft を使います。下訳を使っても CSV の状態を確定訳に変更しません。technical_review・hold・excluded・do_not_translate の行は取り込みません。

`Build ready` が出れば生成成功です。何かキーを押して閉じたら、再度起動して 2 を選びます。反映先が `C:\GameModding\AgeOfDecadence_JP\working` であることを確認し、YES を入力してください。STOP が出た場合は反映しないでください。

生成物は `builds\日時\`、反映前バックアップは `backups\日時\` です。AoD.exe で起動して日本語を選び、変更した画面を確認してください。ビルド成功は実機での表示保証ではありません。

元の source、Steam 本体、セーブデータは変更しません。working の対象ファイルだけを反映します。既存の日本語フォント基盤が必要です。英語と日本語の両方の読み込み先を用意するため、working では英語を選んでも一部日本語になります。

## 戻す

ゲームを終了して 3 を選びます。変更されたファイルはバックアップから戻し、反映で新しく追加したファイルは削除します。バックアップは残ります。反映後に別の処理が対象ファイルを変更していた場合は上書きせず停止します。

## 保存先と GitHub

旧成果物は reference/legacy_work に保存しています。編集には使用しないでください。Git の追跡対象はツール・最新版 CSV・用語集などに限定しています。ゲーム本体、バックアップ、抽出画像、参考 MOD は対象外です。最初は非公開 GitHub リポジトリに接続し、公開前に原文や画像の配布条件を確認してください。

Python の場所が変わった場合は AOD_TOOL_PYTHON を設定してください。ゲームの配置が変わった場合は tools/state/settings.json を変更します。
